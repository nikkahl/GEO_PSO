# Короткий гід для перегляду (для наукового керівника)

Це реалізація дослідження: фізично-обґрунтована навігація рою частинок по
реальній поверхні рельєфу (Українські Карпати, реальний DEM) з геодезичним
критерієм відстані та композитною цільовою функцією, що балансує близькість
до цілі й витрачену роботу (енергію).

## Що подивитись у першу чергу (основне)

**1. Цільова функція** — `src/objective_functions.py`
Композитна функція (формула 1): `f_i = α·(d_geo·k/d_i) + (1−α)·(A_geo/A_cum) → max`
та базова (формула 2): `f_i = d_i → min`. Прошу перевірити, чи правильно
реалізовано баланс α і напрям оптимізації (максимізація композитної).

**2. Модель енергії та роботи** — `src/energy_model.py`
Робота `C = γ·m·g·cosθ + m·g·sinθ`, накопичена робота `A_cum = Σ C·ds`,
розсіяна енергія `E_mech = Σ γ|v|²·Δt`, енергоефективність
`η = E_mech / (D_geo⁰ − D_geo_min)`. Прошу перевірити коректність формул.

**3. Геодезична відстань** — `src/geodesic_distance.py`
Відстань по поверхні (алгоритм Дейкстри по сітці рельєфу з вагою ребра =
справжня 3D-довжина). Чи правильний підхід?

**4. Рівняння руху** — `src/physics_engine.py`
Гравітація вздовж схилу, тертя Релея, кривизна `s = vᵀHv`, пружини,
відштовхування, обмеження швидкості.
