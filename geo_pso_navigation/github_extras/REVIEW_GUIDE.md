
1. `src/objective_functions.py`
Композитна функція (ф 1): `f_i = α·(d_geo·k/d_i) + (1−α)·(A_geo/A_cum) → max`
та базова (ф 2): `f_i = d_i → min`. 

2. `src/energy_model.py`
Робота `C = γ·m·g·cosθ + m·g·sinθ`, накопичена робота `A_cum = Σ C·ds`,
розсіяна енергія `E_mech = Σ γ|v|²·Δt`, енергоефективність
`η = E_mech / (D_geo⁰ − D_geo_min)`. 
Не знаю чи правильно я вивела з того, що було на дошці +  у вас в гітхаб забрала фізику
